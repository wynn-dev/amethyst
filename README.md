# Amethyst

A fast, native-feeling Minecraft launcher for macOS on Apple Silicon.

> **Status:** early development. Nightly builds only.

## Download

**[Amethyst-arm64.dmg](https://github.com/wynn-dev/amethyst/releases/download/nightly/Amethyst-arm64.dmg)**:
the latest nightly build of `main`, for macOS 13 or later on Apple Silicon. It is signed and
notarized, and updates itself. See what's in it on the [nightly release](https://github.com/wynn-dev/amethyst/releases/tag/nightly).

Telemetry is off unless you opt in; see [docs/PRIVACY.md](docs/PRIVACY.md) for exactly what is collected.

## Features (planned)

- Vanilla, Forge, NeoForge, Fabric and Quilt, running natively on Apple Silicon for every Minecraft version
- Isolated instances with deduplicated mods, resource packs and shader packs
- Modrinth and CurseForge browsing, installs and updates; `.mrpack` and CurseForge modpack import/export
- Microsoft and offline accounts, 3D skin viewer, skin and cape changes
- Automatic Java runtime downloads
- Themes and custom backgrounds
- Rolling nightly releases with in-app updates
